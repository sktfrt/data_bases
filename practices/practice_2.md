## Нормальные формы(NF)

**Аномалия** - удаление, изменение и тд в схеме  
Процесс улучшения(удаления аномалий) ***называется нормализацией***

**1 NF:**

1. отсутсвует порядок строк
2. отсутсвует порядок столбцов
3. отсутсвуют дубликаты
4. атомарность(ситуативно)

Процесс разбиение таблицы ***называется декомпозицией***, обратный процесс называется ***денормализацией***  

R = {A1:D1, A2:D2, .. , An:Dn} - схема отношения(Имя:Домен)  
r подмножество D1 x D2 x.. x Dk - отношение
t из D1 x D2 x.. x Dk - кортеж
r1 >< r2 - join, склеивание таблиц  
A -> B - функциональная зависимость - A, B *пожмножество* R => для любых двух туплей из r: t1[A] = t2[A] => t1[B] = t2[B]

Для любого r из Inst(r)(где Inst(R) = {r | r удовлетворяет всем правилам из бизнес логики}):

* A - superkey, если для любых t1, t2 из r: t1[A] = t2[A] => t1 = t2  
* A - candidate key, если A - superkey and Не сущ собственных подножеств у А тч они superkey
* A - primary key, если A -> B: A подмножество A0, A0 - candidate

`NF1 содержит NF2 содержит NF3 содержит BCNF`

**2 NF:**

1. все неключевые атрибуты зависят от ключа, где альфа - неключевой атрибут <=> не сущ A - candidate key: альфа из А
2. зависят от всего ключа, т.е. A -> B что-то из перечисленного:
   * тривиальная(B подмножество А)
   * A - superkey
   * B - ключевой
   * А не является собственным подмножеством кандидатов

**3 NF:**

1. и зависят от ничего кроме ключа
2. A -> B что-то из перечисленного:
   * trivial
   * A - superkey
   * B - ключевой

**BCNF:**(нормальная форма Бойса - Кота)

1. все атрибуты зависят от ключа, всего ключа, и ничего кроме ключа
2. A -> B что-то из перечисленного:
   * trivial
   * A - superkey
