## Реляционная модель данных

Состав модель данных:

* Способы описание данных (Table ..., name string)
* Способы описания взаимосвязей между объектами данных
* Средства задания ограничений целочтности (5 >= grade >= 2)
*

**Реляционная модель** - это группа данных, оснвоанная на принципах реляционной алгебры  
*Таблица* = отношение(relation)  

**Схема отношения** - название + атрибуты отношения  

**Домен** - множество, элементы которого рассматривуется как скалярные, с бинарным отношением равенства  
Домен обязан быть:

* атомарным
* избегаем NULL значений  

**Отношение(у Кодда)** - предикат(ф-ия возвр True\False) на прямом произведении доменов  
> f: A x B x C -> {0, 1} - отношение с тремя атрибутами  

**Целостность бд** - соответсвтие информации у ее внутренней логике  
Типы целостности: ...

Отличия теоритической от практической реализации в реляционных модели:

1) нет дубликатов/есть дубликаты + наличие сортировки
2) наличие NULL
3) ограниченный набор доменов
4) доп операции
